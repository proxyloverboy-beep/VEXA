# VEXA

A mobile voice-assistant prototype for Android.

## Current build
- Hindi/English speech recognition using Android SpeechRecognizer
- Voice-response prototype
- Phone temperature check command
- Clean VEXA interface

## Important
Voice recognition alone cannot guarantee that only one person's voice is accepted. A real voice-lock should use speaker verification/voice embeddings and keep the voice profile encrypted on-device. This project currently provides the voice-command foundation.

## Build
Open this Android project in an Android-capable IDE/build environment and build the `app` module.
